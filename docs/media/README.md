# Media

Generated by `python scripts/train_cascade.py` (for each stage `pitch` and `velocity`):

| File | What |
|---|---|
| `<stage>_train.mp4`, `.gif` | a clip recorded during the training of that stage |
| `<stage>_demo.mp4`, `.gif` | the trained, frozen stage playing back |
| `<stage>_training_curve.png` | reward and episode length over the iterations |

Added by hand before publishing:

| File | What to show | How to make it |
|---|---|---|
| `banner.png` | The Balboa balancing in Isaac Sim (README header, about 1440x600) | Screenshot of the `--viz kit` viewport |
| `robot_render.png` | Isaac Sim render of the Balboa model | Screenshot of the viewport |
| `video_thumbnail.png` | Thumbnail linking to the full video | Any frame of a demo |

Keep GIFs under 10 MB. Put long videos on YouTube and replace `YOUR_VIDEO_ID` in `README.md`.
